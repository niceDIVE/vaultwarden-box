# 03 · 换设备、冲突、出事怎么办

> 这份文档平时不用做，**先通读一遍**（10 分钟），有事时再回来查具体步骤。
> 它回答四个问题：两台设备同时改怎么办、换手机/换电脑怎么搬、忘密码/文件坏了怎么办、多个身份怎么分。

---

## 一、先背下来三条规矩（这是这套方案的命门）

1. **手机以"查看和自动填充"为主，新增和修改尽量在电脑上做。**
   手机端每次保存都要经过网络，冲突的风险全在这一步。
2. **手机弹窗问"合并还是覆盖"时，永远点「合并」。**
   两个按钮挨得很近，点之前看清楚。
3. **看到文件名里带「冲突副本」的文件，不要直接删、不要直接改名用。**
   按第三节的步骤，用 KeePassXC 把它并进主库，确认无误后再删。

---

## 二、冲突是怎么产生的（理解了就不慌）

两边都基于**同一个旧版本**各自做了修改，然后先后上传——后上传的要么覆盖前者，要么被另存为"冲突副本"。

| 场景 | 结果 | 危险度 |
|---|---|---|
| 手机只读、电脑改 | 电脑上传 → 手机下次打开看到新内容 | 无 |
| 手机改了并保存好，电脑随后才保存 | 坚果云通常生成「冲突副本」保住两边 | 低（能合回来） |
| 手机上忽略"文件已变"的提示，继续保存 | **电脑上刚加的条目被覆盖** | **高（这是丢数据的主路径）** |
| 电脑离线改、手机在线也改 | 生成冲突副本 | 低 |
| 手机和电脑打开的是同一份，但都没保存 | 无冲突（没人写） | 无 |

**所以规矩 1 和 2 不是建议，是防丢数据的操作规范。**

---

## 三、已经出现冲突副本了，怎么合回去

### 3.1 先认出它

坚果云在同步文件夹里会多出类似这样的文件（名字里一定有"冲突副本"字样）：

```
main (冲突副本 2026-10-18 22-05-13).kdbx
main-冲突副本.kdbx
```

### 3.2 合并步骤（在电脑上做）

1. 确认电脑上的坚果云已经同步完（图标不转圈）
2. 用 KeePassXC 打开**主库** `main.kdbx`
3. 点菜单「**数据库 / Database**」→「**从数据库合并 / Merge from database**」
4. 选择那个**冲突副本**文件
5. 弹出"合并"对话框：它会列出冲突副本里的分组
   - 默认全选就行
   - 确定
6. 看主库里是不是**两边的条目都在**（例如：电脑加的"银行" + 手机加的"外卖"）
7. 保存主库（`Ctrl+S`）
8. **确认无误后**，把坚果云里那个冲突副本文件删掉（它会进坚果云回收站）

> ⚠️ 顺序不能反：**先合并且保存成功，再删副本**。反过来就是永久丢一半。

> 💡 合并是"加进去"，不是"替换"。同名条目如果两边内容不同，KeePassXC 会保留两个（或按修改时间保留最新），合并后自己看一眼有没有重复项。

## 四、冲突演练（做一次，10 分钟，做完你就真的不怕了）

**前提：电脑和手机都能打开同一个库。**

1. 电脑上：新建分组 `演练`，里面加一条 `电脑写的`，密码随便填 `aaa`。保存。
2. **等 1 分钟**（让坚果云同步完），手机上打开库，确认能看到 `演练 → 电脑写的`。
3. 手机上：在 `演练` 分组里加一条 `手机写的`，密码 `bbb`。保存。
4. **立刻**（不要等同步）回到电脑，也在 `演练` 里加一条 `电脑写的2`，密码 `ccc`。保存。
5. 这时两边都改过 → 大概率会出现冲突副本。
6. 等同步完，看坚果云文件夹里有没有"冲突副本"：
   - **有** → 按第三节合并，确认 `电脑写的`、`手机写的`、`电脑写的2` **三条都在**
   - **没有** → 说明冲突被自动合了，也检查三条是否都在
7. 把 `演练` 分组**整组删掉**（它会进回收站，再清空回收站）

> ✅ 演练成功的标准：**三条测试条目一条不少**。
> 如果少了任何一条，说明规矩 2 没执行到位——回到第一节重读，别急着用真账号。

## 五、换手机

好消息：**不需要旧手机在场**，因为文件在云端。

1. 新手机装 Keepass2Android（安装包在 `F:\passworg box\local-vault\downloads\`，或用旧手机把这文件传过去）
2. 打开 App →「打开数据库」→「WebDAV」
3. 填：
   - 地址：`https://dav.jianguoyun.com/dav/`
   - 用户名：坚果云账号邮箱
   - 密码：**应用密码**
4. 进 `Passwords` → 打开 `main.kdbx` → 输入主密码
5. 按文档 01 第 8 步设置自动填充服务

> 旧手机怎么处理：先在新手机上确认能打开、能看到条目，**再**把旧手机的 Keepass2Android 卸载（或直接清空手机）。
>
> ⚠️ 如果应用密码找不到了：登录坚果云网页版 → 账户信息 → 安全选项 → 第三方应用管理 → 重新添加一个应用密码（旧的可以删掉）。**主密码不变。**

## 六、换电脑

1. 新电脑装 KeePassXC（用同一个安装包）
2. 装坚果云客户端，登录同一个账号
3. 等它把 `Passwords/main.kdbx` 同步到本地
   - 如果只看到占位文件：右键 →「下载 / 始终保留在此设备上」
4. 用 KeePassXC 打开 → 输入主密码
5. 按文档 01 第 4 步做那三处设置
6. 把备份脚本重新装一遍：双击新电脑上的 `安装每日备份.bat`（备份是**按电脑**装的，不会跟着账号走）

> ⚠️ 旧电脑处理：确认新电脑能用之后，旧电脑上的 KeePassXC 要卸载，坚果云客户端要退出登录（否则旧机器上还留着加密文件——虽然打不开，但没必要留着）。
>
> **别删坚果云上的文件**，那是你唯一的云端副本。

## 七、忘主密码了怎么办（先说结论：救不回来）

KeePassXC 没有找回功能，没有客服，没有后门，**这是设计而不是缺陷**——如果有找回通道，那它就不安全了。

所以现在的做法只有一个：**回到那张纸**。

如果纸也丢了，这个文件就永久打不开了。你能做的只有：

1. 停止一切操作，**别覆盖任何文件**
2. 回想是否还有别的副本（U 盘、旧电脑、坚果云历史版本）——**注意：它们都是同一个主密码加密的，密码忘了，副本再多也打不开**
3. 接受现实：重新建库，把所有账号走一遍"忘记密码 → 邮箱重置"流程

> 这就是为什么文档 02 里那张纸要"和 U 盘分开放"、要手写、不要拍照——它是唯一不依赖电子设备的保险。

## 八、文件坏了 / 被删了怎么办（按这个顺序找）

从**最近**到**最远**，找到能打开的为止：

| 顺序 | 在哪 | 怎么找 |
|---|---|---|
| 1 | 坚果云"冲突副本" | 文件夹里带"冲突副本"的文件 |
| 2 | KeePassXC 的保存前备份 | `Passwords` 目录里名字带 `.bak` 或 `.old` 的文件 |
| 3 | `D:\kdbx-backup\` | 按日期找，挑最近能打开的 |
| 4 | 坚果云历史版本 | 网页版 → 右键文件 →「历史版本」 |
| 5 | U 盘 | 那份离线副本 |
| 6 | 旧电脑 / 旧手机 | 如果还没清空 |

找到能打开的之后：

1. 复制一份到桌面，改名 `修复.kdbx`
2. 用 KeePassXC 打开验证
3. 确认内容完整 → 用它替换 `Passwords\main.kdbx`（**替换前先把坏的改名留档**，别直接删）
4. 手动跑一次备份：双击 `立即试跑一次.bat`

## 九、多个身份怎么分（一个文件，还是一堆文件）

Opus 的建议，照搬：

- **默认：一个文件，每个身份建一个顶级分组。**
  例如顶级分组：`个人`、`工作`、`家人共用`、`项目A`。
- **只有一种情况才单独开第二个文件**：某个身份必须连"存在"都不让另一个看到
  （例如：你要把某个库交给别人代管，或者某个库的存在本身就是秘密）。
- **文件每多一个，同步和冲突的麻烦就多一份。** 两个文件的代价不是两倍，是"两套备份、两套冲突处理、两份要记的主密码"。

> 实践建议：先用一个文件把所有东西装进去，分组分清楚。等真的被"存在性"问题卡住了，再拆。

## 十、手机端使用注意（贴墙上的那种）

| 要做 | 不要做 |
|---|---|
| 用自动填充 | 在手机上大批量新增/修改条目 |
| 弹"合并/覆盖"时点**合并** | 点"覆盖"或"忽略" |
| 只读时用"重新加载" | 登录后忘了保存就退出（其实"只是看"不写文件，安全） |
| 换手机前先确认新手机能用 | 先清空旧手机 |

补充两条安全习惯（来自 Opus 的威胁模型表）：

- **主邮箱的二步验证（2FA）恢复码，不要放进这个 kdbx。** 手机丢了、库丢了，你要靠邮箱来找回，而邮箱的救命码正好在丢掉的库里——那就死锁了。把 2FA 恢复码单独打印在另一张纸上，和 U 盘分开放。
- **主密码只在 KeePassXC 的窗口里输入。** 任何网页、任何"请输入您的密码以继续"的弹窗，都不是。
