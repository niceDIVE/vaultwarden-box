# 01 · 安装与首次设置

> 做完这份文档，你会得到：**电脑上能开库、手机不依赖电脑也能看密码、网页能自动填。**
> 全程照着做，每一步都有「✅ 成功标志」和「❌ 卡住了怎么办」。**对不上就停，别硬往下走。**

---

## 开始之前，先理解三个词（1 分钟）

| 词 | 是什么 | 你要记住的 |
|---|---|---|
| **数据库 / main.kdbx** | 一个文件，里面装着所有密码。文件本身是加密的乱码 | 它叫 `main.kdbx`，放在坚果云同步文件夹里 |
| **主密码** | 打开这个文件的唯一钥匙 | **记脑子里 + 抄在纸上**。忘了就永久打不开，没有找回 |
| **应用密码** | 坚果云给"其他软件"发的专用密码 | 只填在 Keepass2Android 里，跟你的主密码是两回事 |

⚠️ 最容易搞混的地方：**主密码** ≠ **坚果云登录密码** ≠ **坚果云应用密码**。三个都不同。

---

# 第 1 步：坚果云（10 分钟）

坚果云在这里的唯一作用是"把文件从电脑搬到手机"。它看到的是加密后的乱码。

### 1.1 注册 / 登录

1. 打开浏览器，进 `https://www.jianguoyun.com`
2. 有账号就直接登录；没有就点注册（要手机号）
3. 免费版够用（一个 kdbx 只有几十 KB）

### 1.2 生成"应用密码"（这步最容易漏）

1. 登录后，点右上角**你的账号名**
2. 选「**账户信息**」
3. 选「**安全选项**」
4. 找到「**第三方应用管理**」→ 点「**添加应用密码**」
5. 名称填 `keepass` → 点「**生成密码**」
6. **把生成出来的那串密码复制下来，先粘贴到记事本里存着**（手机端要填它）

> 这串密码只在这里用。它和你的坚果云登录密码不是一个东西——**手机端填的必须是这串应用密码**，填登录密码会连不上。

### 1.3 装 Windows 客户端

1. 打开 `https://www.jianguoyun.com/s/downloads`
2. 下载 Windows 版，双击安装，一路下一步
3. 装完用你的坚果云账号登录

### 1.4 找到同步文件夹，建一个 Passwords 目录

1. 客户端装好后会有一个**本地同步文件夹**（安装时可能让你选，默认类似
   `C:\Users\WANG\Nutstore\我的坚果云`）
2. 在客户端界面里能看到这个路径，**把它复制下来记在记事本里**（第 5 步备份要用）
3. 打开这个文件夹，在里面**新建一个文件夹**，名字就叫 `Passwords`（注意大小写，P 大写）

> ✅ **成功标志**：坚果云客户端图标正常（不转圈、不报红），你能打开那个 `Passwords` 文件夹。
> ❌ 卡住了：客户端一直显示"未同步"→ 先检查能不能正常登录网页版；换网络（手机热点）再试。

# 第 3 步：生成主密码，建库（10 分钟）

### 3.1 先生成主密码

1. 双击 `F:\passworg box\local-vault\生成主密码.bat`
2. 黑窗口会显示 3 组候选，每组 6 个英文单词，用 `-` 连接，例如 `词-词-词-词-词-词`
3. **挑一个你读两遍就记得住的**（读音顺口比"看着随机"重要得多）
4. **抄在一张纸上**（现在就先抄，别等）
5. 关掉黑窗口

规则（Opus 的原话，我照搬）：
- **不要**加密钥文件（丢了就打不开，风险大于收益）
- 全部小写、只记词和连字符，别自己加符号和大小写，否则以后记不住
- 不要截图、不要发微信、不要存进任何网盘或笔记软件

### 3.2 新建数据库

1. KeePassXC 里点「**数据库 / Database**」→「**新建数据库 / New Database**」
2. 数据库名填 `main`
3. 保存位置选到 **`<坚果云同步文件夹>\Passwords\`**，文件名 `main.kdbx`
4. 加密设置那一页：**什么都别改**（默认 KDBX 4 + Argon2id 就是最好的）
5. 主密码：输入 3.1 抄下来的那串口令（要输两遍）
6. 「密钥文件 / Add key file」这一页：**跳过**（点下一步/继续）
7. 完成

> ✅ **成功标志**：KeePassXC 窗口标题显示 `main.kdbx`，左边树里能看到"常规/General"分组，是空的。
> ❌ 卡住了：如果提示文件已存在 → 说明 `Passwords` 里已经有同名文件，先改名或删掉再建（别覆盖）。

### 3.3 验证"文件真的在那个文件夹里"

打开资源管理器，进 `<坚果云同步文件夹>\Passwords\`，应该能看到 `main.kdbx`。

> ⚠️ 如果这里看到的是一个**只有几 KB 的"占位"文件**（坚果云在线文件），要右键选「**下载 / 始终保留在此设备上**」，等它变成真实的本地文件。
> 判断方法：文件大小在 2KB 以上，且不是灰色云朵图标。

# 第 4 步：KeePassXC 三处设置（5 分钟）

打开「**工具 / Tools**」→「**设置 / Settings**」。

> 界面可能是中文也可能是英文（取决于系统语言），按**意思**找，别死抠字。

### 4.1 「常规 / General」页

勾选这两项（名字大意如下，勾"意思等于这两句"的就好）：

- ☑ **保存后自动重新加载外部修改**
  （电脑上开着库，手机改了同一个文件 → KeePassXC 会自动重新读，不会用旧内容覆盖）
- ☑ **保存前备份数据库**
  （每次保存前留一份上一版）

> ⚠️ 第一条对你这套方案**特别重要**：手机是通过网络直接改云端的，电脑这边必须能感知到外部改动，否则你一保存就把手机加的东西盖掉了。

### 4.2 「安全 / Security」页

- **空闲自动锁定**：设成 `5` 分钟
- **复制到剪贴板后清除**：设成 `10` 秒
- （如果有「锁定时清除剪贴板」，勾上）

### 4.3 打开回收站（数据库设置里）

1. 点「**数据库 / Database**」→「**数据库设置 / Database Settings**」
2. 找「**回收站 / Recycle Bin**」页
3. 勾选「**启用回收站**」
4. 确定

> ✅ **成功标志**：删条目时它进回收站，不是直接消失。
> 这一项救了无数"手滑删了一个账号"。

# 第 5 步：浏览器扩展（10 分钟，可选但强烈建议）

### 5.1 在 KeePassXC 里打开集成

「工具 → 设置 → **浏览器集成 / Browser Integration**」→ 勾选你用的浏览器（Chrome / Edge / Firefox）。

### 5.2 装扩展

1. 打开你的浏览器扩展商店，搜 **`KeePassXC-Browser`**
2. 安装
3. 浏览器里点扩展图标 → 会提示"连接 KeePassXC" → 点**连接** → KeePassXC 弹窗 → **允许**

Edge 加载项商店（`microsoftedge.microsoft.com`）在国内一般能打开；Chrome 商店可能需要网络条件。

> ✅ **成功标志**：扩展图标不再是灰的，登录网页时会在输入框旁出现 KeePassXC 的图标。
> ❌ 商店打不开：**跳过这一步**，改用"复制粘贴"——KeePassXC 里对条目按 `Ctrl+B` 复制用户名、`Ctrl+C` 复制密码，粘贴到网页。安全性略降（剪贴板），但完全可用。
>
> ⚠️ 安全习惯：**主密码只在 KeePassXC 的窗口里输入，任何网页都输。** 如果某网页的输入框突然不自动填充了，那是扩展在提示你"域名对不上，可能是钓鱼"——这时**不要**手动复制粘贴上去，先看清网址。

# 第 6 步：手机装 Keepass2Android（10 分钟）

> **为什么不是 KeePassDX**：Opus 的判决里明确改了这一点。Keepass2Android 保存时如果发现文件被别的设备改过，会弹窗让你选「合并」，合并算法和 KeePassXC 一致；KeePassDX 只提示"文件已变"，你不理会继续保存就会把电脑上新加的条目盖掉。**这个差别就是"丢不丢数据"，所以用它。**

### 6.1 把安装包传到手机

任选一种：
- 微信「文件传输助手」发给手机，手机上点开安装
- 数据线连电脑，把文件复制到手机存储里，再用手机文件管理器点开

安装包在：`F:\passworg box\local-vault\downloads\keepass2android-v1.15-r6-universal.apk`

### 6.2 安装

1. 手机上点开这个 apk
2. 系统可能提示"不允许安装未知来源应用"→ 点「设置」→ 允许你这个文件管理器/微信安装
3. 装完点「打开」

> ✅ **成功标志**：手机桌面出现 Keepass2Android 图标，打开后是"打开数据库"的选择界面。

---

# 第 7 步：手机上连坚果云、打开库（5 分钟）

1. 打开 Keepass2Android → 点「**打开数据库**」（Open database）
2. 在列表里找「**WebDAV**」（可能写作 "https / WebDAV"）
3. 按下面填：

| 填什么 | 填成 |
|---|---|
| 服务器地址 / URL | `https://dav.jianguoyun.com/dav/` |
| 用户名 / UserName | 你的**坚果云账号邮箱** |
| 密码 / Password | **应用密码**（第 1.2 步生成的那串，不是登录密码） |

4. 连上后浏览文件夹：进入 `Passwords` → 选中 `main.kdbx`
5. 输入**主密码**（第 3.1 步那张纸上的）

> ✅ **成功标志**：看到了你在电脑上建的分组/条目。
> 到这里，**这套方案就成立了**：手机不再依赖电脑开机，直接从云端打开加密文件。

❌ 常见失败：

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 一直连不上 / 401 | 填了登录密码 | 改填**应用密码** |
| 能连上但看不到文件 | 还没同步上去 | 等电脑端坚果云显示"已同步"再试 |
| 提示"网络不给力" | 应用被限制联网 | 手机设置里允许 Keepass2Android 使用移动网络/WLAN |

---

# 第 8 步：手机自动填充（5 分钟）

1. 打开手机「**设置**」
2. 找「**系统**」→「**语言和输入法**」（不同品牌路径略有差异）
3. 点「**自动填充服务**」
4. 选「**Keepass2Android**」
5. 打开 KeePass2Android → 设置里确认「自动填充」已开启

**测试**：浏览器打开任意登录页 → 点用户名输入框 → 应该弹出 Keepass2Android 的填充建议。

> 更省事的方式：先在电脑上把常用网站（银行、邮箱、购物）各建一条条目，手机上直接就能填。
