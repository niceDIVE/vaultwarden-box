# 02 · 每日备份与离线份

> 目标：**每天自动多一份带日期的副本；U 盘里有一份拔下来的离线份；纸上有一份手写的钥匙。**
> 这三样东西防的是三件不同的事，缺哪样都补不上。

---

## 一、先搞清楚：这三份东西各防什么

| 备份 | 防什么 | **不防**什么 |
|---|---|---|
| `D:\kdbx-backup\` 的 30 份 | 手滑误删、改错了想回退、文件写坏 | **不防勒索软件**（同一台电脑，会被一起加密） |
| U 盘里那份（平时拔掉） | 勒索软件、电脑整机挂掉、电脑被偷 | 不防"你三个月没更新过它" |
| 纸上那一行主密码 | **忘记主密码**（比文件丢了更常见） | 不防别人看到这张纸（所以要收好、要和 U 盘分开放） |
| 坚果云的"历史版本" | 云上文件被覆盖后的找回 | 不防云账号本身出事 |

**记住一句**：本地那 30 份是用来救误操作的，不是用来防勒索的。真正的防线是那支平时不插着的 U 盘。

---

## 二、装每日自动备份（一次性，5 分钟）

### 2.1 双击安装

1. 打开 `F:\passworg box\local-vault\`
2. 双击 **`安装每日备份.bat`**
3. 会出现一个黑窗口，它会：
   - 把备份脚本装到 `C:\Users\WANG\AppData\Local\kdbx-backup\`
   - 注册一个名叫 `kdbx-backup` 的计划任务，**每天 12:00 运行**
   - 立刻试跑一次，把结果显示在屏幕上

### 2.2 你应该看到什么

成功的话，屏幕上会有类似这样的一段：

```
==========================================
 密码库每日备份 · 安装程序
==========================================

✓ 找到备份脚本：F:\passworg box\local-vault\kdbx-backup.ps1
✓ 已安装到：C:\Users\WANG\AppData\Local\kdbx-backup\kdbx-backup.ps1
✓ 已注册计划任务：每天 12:00 自动备份

──────────────── 试跑一次备份 ────────────────
2026-10-18 12:00:03  成功：main-20261018.kdbx（4,104 字节，SHA-256 67017953E3D3…）
2026-10-18 12:00:03  当前保留 1 份，最旧 main-20261018.kdbx，最新 main-20261018.kdbx

✓ 试跑成功。备份文件在 D:\kdbx-backup\，日志在同目录 backup-log.txt。
```

**看到"✓ 试跑成功"才算装好。**

### 2.3 如果它说"找不到密码库文件"

说明脚本没自动找到你的 `main.kdbx`（坚果云的同步文件夹路径可能不是默认的）。手动告诉它：

1. 打开 `C:\Users\WANG\AppData\Local\kdbx-backup\`
2. 在空白处右键 →「新建」→「文本文档」，名字改成 `kdbx-path.txt`
   （**注意**：如果看不到 `.txt` 后缀，说明系统隐藏了扩展名，先按下面 2.4 打开扩展名）
3. 用记事本打开它，**第一行写密码库的完整路径**，例如：
   ```
   C:\Users\WANG\Nutstore\我的坚果云\Passwords\main.kdbx
   ```
   （路径以你实际看到的为准，可以在资源管理器地址栏复制）
4. 保存，关掉
5. 重新双击 `安装每日备份.bat`

### 2.4 让 Windows 显示文件后缀（强烈建议做一次，以后少踩坑）

资源管理器 → 顶部「查看」→ 勾选「**文件扩展名**」。

## 三、验证备份真的在工作（分两次，跨一天）

这件事**必须验证两次**，因为"第一次成功"和"每天都会跑"是两回事。

### 第一次：现在就验

1. 打开 `D:\kdbx-backup\`
2. 应该有一个 `main-<今天日期>.kdbx`，例如 `main-20261018.kdbx`（大小和你的 main.kdbx 一样）
3. 应该有 `backup-log.txt`，打开看最后一行是"成功"

### 第二次：明天再验（这一步不能省）

明天中午 12 点之后，打开 `D:\kdbx-backup\`，看是不是多了一个 `main-<明天日期>.kdbx`。

- **多出来了** → 计划任务真的在工作 ✅
- **没多出来** → 说明它只在手动跑时成功。按下面查：

| 检查 | 怎么做 |
|---|---|
| 任务在不在 | 开始菜单搜「任务计划程序」→ 左侧「任务计划程序库」→ 找 `kdbx-backup` |
| 上次运行结果 | 双击它 →「上次运行结果」。`0x0` = 成功；其它数字 = 失败（把截图发我） |
| 是不是电脑当时关机了 | 脚本设置的是"错过就补跑"（StartWhenAvailable），但机器必须开着 |

> ⚠️ 这台电脑如果经常中午不在，把时间改到你常在的时候。用管理员命令提示符跑：
> ```
> schtasks /Change /TN kdbx-backup /ST 21:30
> ```

## 四、这个脚本比你想象的更严（看一眼就懂，不懂也能放心）

它做了三件"直接复制不会做"的事：

1. **先写成 `.part` 临时文件，校验通过才改名**
   → 复制中途断电/失败，不会留下一个"看起来像备份、其实是半截"的文件
2. **比对源文件和副本的 SHA-256**
   → 复制过程出任何差错会被发现，不会静默产生坏备份
3. **检查文件头是不是真正的 KDBX 格式**
   → 抓得出"坚果云占位文件""0 字节文件""没下载完的文件"

还有两条行为保证：

- **出错时绝不删除任何旧备份**（只写日志、退出码 1）
- 只保留最近 **30 份**，多的自动清理（文件名带日期，按日期排序）

## 五、U 盘那份（唯一能防勒索的东西）

### 5.1 准备一个 U 盘

随便一个 4GB 以上的都行。**平时拔掉收在抽屉里**，不要长期插着——插着就会被勒索软件一起加密。

### 5.2 多久更新一次

- **每月一次**（定个手机日历提醒）
- **加了重要账号之后**（银行、主邮箱、支付）顺手再更新一次

### 5.3 怎么更新（3 分钟）

1. 插上 U 盘
2. 打开 `D:\kdbx-backup\`，找**文件名日期最新**的那个 `main-<日期>.kdbx`
3. 复制它，粘贴到 U 盘根目录
4. 把 U 盘里旧的 `main-*.kdbx` 删掉（**只留最新一份**，不然你以后分不清哪个新）
5. 拔掉 U 盘

> 文件名很重要：**保留带日期的那种名字，别改成 `备份.kdbx`**。半年后你会庆幸它带着日期。

### 5.4 每季度必须做一次：试着打开它

**打不开的备份等于没有备份。** 每季度（3 个月）做一次：

1. 插 U 盘
2. 用 KeePassXC 打开 U 盘里那个文件（文件 → 打开数据库 → 选 U 盘里的）
3. 输入主密码
4. 能看到条目 → ✅ 这份备份是活的
5. 关掉，拔掉 U 盘

如果这一步打不开，立刻做两件事：**① 别覆盖 U 盘里的旧文件 ② 把报错截图发我。**

## 六、纸上那份（唯一能救"忘密码"的东西）

拿一张纸，手写三行：

```
主密码：（第 3.1 步抄的那串词）

文件在哪：坚果云 → 我的坚果云 → Passwords → main.kdbx
          电脑本地：C:\Users\WANG\Nutstore\我的坚果云\Passwords\main.kdbx

用什么打开：电脑 —— KeePassXC
            手机 —— Keepass2Android
```

然后：

- **和 U 盘分开放**（一个被偷/被烧，另一个还在）
- 不要放钱包（会丢）
- 不要拍照存手机（那就等于存在电子设备里了）
- 家里人不知道这是什么也没关系，纸上的"文件在哪、用什么打开"足够一个懂电脑的人帮你恢复

> 为什么这么重视这张纸：**忘记主密码是所有密码管理器最常见的死法**，比被黑常见得多。
> KeePassXC 没有找回功能，没有客服，没有后门。忘了就是永久打不开——所以纸上那一行，是你唯一的保险。

## 七、坚果云自己的"历史版本"（顺手知道一下）

坚果云对每个文件保留历史版本。万一 `main.kdbx` 被覆盖错了：

1. 登录 `https://www.jianguoyun.com` 网页版
2. 找到 `Passwords/main.kdbx`
3. 右键 →「历史版本」→ 挑一个时间点恢复

这是**第三道**保险，但它依赖云账号本身没出事，所以**不能替代** U 盘和本地备份。

## 八、半年做一次"恢复演练"（10 分钟，别跳过）

备份不算数，**能恢复的备份**才算数。每半年做一次：

1. 打开 `D:\kdbx-backup\`，挑一个**几天前**的 `main-<日期>.kdbx`
2. 复制到桌面，改名叫 `演练.kdbx`
3. 用 KeePassXC 打开它，输入主密码
4. 能看到条目 → ✅
5. 关掉，把 `演练.kdbx` 删掉

（**不要**直接在主库上做这个操作。）

## 九、这份文档的验收清单

## 十、如果以后想卸载 / 停用

- **暂停自动备份**：任务计划程序 → 找到 `kdbx-backup` → 右键「禁用」
- **彻底删除**：管理员命令提示符执行
  ```
  schtasks /Delete /TN kdbx-backup /F
  ```
  然后删掉 `C:\Users\WANG\AppData\Local\kdbx-backup\` 文件夹。
  `D:\kdbx-backup\` 里的备份**不会**被删，要删自己手动删。
